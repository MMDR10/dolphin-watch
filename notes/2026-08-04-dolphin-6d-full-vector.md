## 研究方法

- 數據：GFS 0.25°（NOMADS subset，850+200 hPa U/V），4 時次：8/1 00z / 8/2 00z / 8/3 12z / 8/4 00z
- 中心：exact-center（用 dhcurl_history.json 已定中心，唔自動偵測）
- Protocol：Core=5° / Shell=10°；標準化 vorticity 耦合場 c = z₈₅₀·z₂₀₀
- θ₁：核心區 (z₈₅₀, z₂₀₀) 2D PCA 主軸角（**空間 adaptation**——文檔定義係時間序列 PCA）
- χ_eff：Var(c)/Mean(c)（核心區 + 正耦合版本）
- H：Pearson r(z₈₅₀, z₂₀₀) 全域/核心/外殼 + ΔH 核殼分解
- D₁：Var(c⁺)/Mean(c⁺)（單快照值，非文檔 Cascade Ratio）

### 1. dH_curl 同 v8 歷史序列一致 ✅
8/4 00z 實測 −2.03e-05 vs v8 記錄 −2.04e-05（差異 0.5%），protocol 正確。
8/1 −4.56e-05 vs 記錄 −4.52e-05（0.9%）、8/2 −5.50e-05 vs −5.49e-05（0.2%）——全部吻合。

### 2. θ₁ 首次實測：強颱風 ~28°（部分有序）⚠️
- 強颱風期（8/1-8/2）：**27.7-28.4°**——介乎 ENSO 9.8°（高度有序）同 random 55° 之間，符合「強颱風係部分有序結構」
- 減弱期（8/3）：**88.7°**——近無序/正交，核心耦合結構消失
- 8/4 00z：0.17°——core 退化（z₈₅₀ 單軸主導），**唔可以解讀做「更有序」**，係核心無有效 850/200 耦合結構
- **詮釋要小心**：θ₁ 喺颱風域用空間 PCA（文檔定義係時間序列 PCA），數值只可做強/弱對比，唔可以直接同 ENSO 9.8° 比較

### 3. H_core：強颱風 vs 減弱嘅清晰 discriminator ✅ NEW
- 強颱風期（8/1-8/2）：H_core = **0.79-0.85**（850/200 核心高度耦合）
- 減弱後（8/3-8/4）：H_core ≈ **−0.04 ~ 0**（耦合崩潰）
- ΔH：強颱風 +0.63~+0.84（Core-organized）→ 8/3 轉負（−0.039，Shell-dominated）
- **物理意義**：強颱風嘅垂直耦合（850 渦度 ↔ 200 渦度）係核心結構核心；減弱首先反映喺垂直耦合崩潰

### 4. D₁ 單快照值：強颱風期爆炸性碎裂 ⚠️
- 強颱風期 D₁ = 178-217（>50「爆炸性碎裂」級別）
- 8/4 00z D₁ = 1.8（COMPACT 級別）
- **注意**：呢個係單快照 D₁ = Var(c⁺)/Mean(c⁺)，**唔係**文檔分類用嘅 D₁ Cascade Ratio（D₁(decay)/D₁(genesis)）。單快照 D₁ 喺強颱風期大係因為核心區極端耦合值（眼牆）令 Var 大——詮釋需謹慎

### 5. χ_eff 喺颱風域定義唔穩定 ⚠️ NEW 發現
- χ_eff = Var(c)/Mean(c)，當核心區 Mean(c)≈0（850/200 無相關時）ratio 爆炸或變負
- 實測：8/1 254.9 / 8/2 215.0 / **8/3 −4.5（負值）** / 8/4 22.5
- **文檔「~3.0 強約束」基準係其他域**；颱風域 χ_eff 對 Mean(c) 極度敏感，唔可以直接套用分類
- 需要重新定義（如用 |c| 或 c⁺ 版本）先可以喺颱風域用

### 6. Ô：引用已有實測 ✅
- 颱風域 Ô balance 已有 IBTrACS 微觀尺度實測 **2.58×**（Continuous Flow，`typhoon-wp-basin-ohat-scale-transition.md`）

## 討論

- **H_core 係今次最強新發現**：單一標量（850/200 核心 Pearson 相關）可以分開強颱風（0.79-0.85）同減弱（~0），同 dH_curl 互補（dH_curl 反映水平結構梯度，H_core 反映垂直耦合）
- θ₁ 空間 adaptation 係颱風域特有問題：文檔定義（時間序列 PCA）需要多時次軌跡；單快照空間 PCA 只可以做相對對比
- χ_eff 定義喺颱風域失效（Mean(c)→0 奇異），係框架應用喺新域常見嘅「定義遷移」問題
- 限制：4 時次、單颱風（Dolphin）；需要跨颱風驗證（WPAC 6 颱風）先可以升格做通則
